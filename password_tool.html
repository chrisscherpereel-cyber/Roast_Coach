    Where this goes

    1. Open your app on share.streamlit.io.
    2. Press the ⋮ menu beside it, then Settings, then Secrets.
    3. Paste the block above into the box, replacing whatever is there.
    4. Press Save. The app restarts on its own and asks for a sign-in.

    Running it on your own machine instead? Save the same text as .streamlit/secrets.toml next to app.py. That path is already in .gitignore — never commit it.

    Adding someone later means pasting the whole block again with their line included, so keep a copy somewhere safe — a password manager, not the repository. Removing a line locks that person out the next time the app restarts.
